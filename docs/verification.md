# 验证记录与版本说明

以下为发布时的验证记录，不代表已在所有电脑和手机上完成验收。

## Windows 0.3.1 切句抖动修复

正常播放时，不再把每次轮询读到的重复进度当作新的起点：避免刚切下一句，又被尚未更新的客户端滑块拉回上一句。小幅校正保持显示进度向前，按当前倍速最多推算一秒；停滞时冻结预测。手动定位、单句循环、客户端明显回退、换歌和暂停仍可正常更新定位。本地播放器不经过远端进度过滤。

2026-10-07：27 项测试覆盖旧问题复现、80 毫秒歌词边界、0.5/1/1.5 倍速、重复样本、进度停滞、手动和外部定位、循环、暂停和乱序样本；EXE 的 --smoke-test 新增同一复现检查。


## 测试

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe main.py --smoke-test
dist\0.3.1\FollowSinger\FollowSinger.exe --smoke-test
```

测试覆盖 LRC 解析、译文对齐、语言辅助、搜索匹配、Qt 鼠标播放与空格快捷键、倍速路由、切换音源后的倍速保持、断连状态与五皮肤设置保存。`--smoke-test` 检查五语界面、显示开关、五皮肤截图、本地音频解码与静音播放、倍速及 960×700 布局，结果和截图保存在运行入口旁的 `output/`。

2026-10-07 更新：18 项测试通过；源码窗口 11 项检查通过，新增法语 IPA、无重音字母法语识别、五语汉字谐音、默认关闭、切换不重建行、原音标保留及手动语言选择保持。此前已对当前网易云直连执行 0.75 倍速切换和播放／暂停往返验证，并恢复原状态。Windows 媒体会话回退未实机验收；实际声卡时延未测量。

0.3.1 EXE 交付：打包后的 `FollowSinger.exe` 直接运行通过 11 项窗口／播放器检查，包含五语读音与译文、五语新手模式与默认关闭、显示开关、五种皮肤、本地倍速和紧凑布局，法语音标 DLL 与数据从包内离线加载成功。源码版真实 Qt 鼠标点击定位和单句循环已验证。便携包附带 `SOURCE/`、eSpeak NG 对应源码和第三方许可证；打包时隔离构建机器的工具 DLL 路径，统一 Python/Qt 的 MSVC 运行库。尚未在全新 Windows 电脑上测试。
