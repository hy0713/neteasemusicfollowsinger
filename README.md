# 跟唱伴学 · FollowSinger

一个 Windows 桌面歌词跟唱练习程序，参考[咏伴 · Utatomo](https://github.com/AsaMisogi/Cloudmusic-Lyrics-Singing)的功能思路重新组织界面与练习流程，并加入俄语、法语、韩语读音辅助。支持本地音频、网易云歌曲歌词搜索，以及跟随网易云客户端播放。

## Android 手机版

新增 [Android 0.1.0](android/README.md)：可安装 APK，支持 Android 8.0 以上，提供五语离线读音、新手汉字谐音、五种皮肤、本地跟唱播放器和网易云媒体会话连接。[下载手机版 APK 与源码](https://github.com/hy0713/neteasemusicfollowsinger/releases/tag/android-v0.1.0)。手机安装与构建说明见 Android 文档。手机版与 Windows 版分别构建；网易云手机端提供的定位和倍速能力需要真机核对。

## Windows 0.3.1 切句抖动修复

正常播放时，不再把每次轮询读到的重复进度当作新的起点：避免刚切下一句，又被尚未更新的客户端滑块拉回上一句。小幅校正保持显示进度向前，按当前倍速最多推算一秒；停滞时冻结预测。手动定位、单句循环、客户端明显回退、换歌和暂停仍可正常更新定位。本地播放器不经过远端进度过滤。

2026-10-07：27 项测试覆盖旧问题复现、80 毫秒歌词边界、0.5/1/1.5 倍速、重复样本、进度停滞、手动和外部定位、循环、暂停和乱序样本；EXE 的 --smoke-test 新增同一复现检查。

## 目前可用的功能

- **五种语言**：日语假名/罗马音、英语美式词典 IPA、俄语拉丁转写、法语本地 IPA、韩语罗马字。法语使用内置 eSpeak NG 离线引擎。自动检测兼顾文字和常见法语词；识别不对时可手动选择“法语”，手动选择不会被下一首歌覆盖，选“自动”可恢复识别。
- **新手模式**：默认关闭。顶部勾选后，在原音标／读音与原文之间追加“谐音参考”；例如 `Hi → 嗨`、`Bonjour → 邦茹尔`。五种语言都支持，按普通话音节与读音的近似距离匹配常用汉字，词间用点分隔。日语使用本地假名／罗马音生成，其余语言使用本地 IPA 生成，无需联网。保留原有音标和译文，可独立开关。
- **跟唱练习**：按 LRC 时间逐句高亮、点击句子定位、上一句/下一句、单句循环、歌词时间偏移。本地音频和支持歌曲倍速的网易云直连支持 0.5–1.5 倍速。空格播放／暂停，文本输入框中保留空格输入。
- **五种皮肤**：时尚绿、护眼黄（米黄色）、海浪蓝、经典白、夜间黑。左侧底部选择，自动保存到 `data/preferences.json`，默认经典白。日语假名／罗马音继续使用本地 pykakasi 转换。
- **本地资料**：打开本地音频后自动读取同名 `.lrc` 和 `.zh.lrc` / `.trans.lrc`；也能手动导入 LRC。支持 UTF-8、UTF-16、GB18030。
- **网易云**：读取 Windows 媒体会话中的当前曲目，搜索匹配网易云公开歌词；如通过客户端直连启动，还可获取其播放时间轴和进行播放/定位控制。
- **体验示例**：五种语言各有原创短句、中文译文和一段合成提示音，无版权歌曲或人声。

## EXE 启动

在 GitHub 上使用时，从 [最新版 Releases](https://github.com/hy0713/neteasemusicfollowsinger/releases/latest) 下载 `FollowSinger-0.3.1-windows-x64.zip`，完整解压后启动里面的 `FollowSinger.exe`。源码仓库不包含本地 `dist/`、运行日志和开发虚拟环境。

Windows 10/11 x64 用户直接双击 **`FollowSinger.exe`**。新版 0.3.1 构建位置是 `dist/0.3.1/FollowSinger/FollowSinger.exe`；便携 ZIP 完整解压后，在 `FollowSinger` 文件夹内启动。便携版内置 Python、Qt、离线词库、法语音标引擎及五语示例，无需安装 Python，也无需运行 BAT。移动程序时请移动整个 `FollowSinger` 文件夹，保留 `_internal`。日志保存在 EXE 同目录下的 `data/logs/`。

界面采用侧栏、居中歌词与底部播放栏，颜色随皮肤切换。读音提示放在原文上方，译文在下方。顶部可选择学习语言、切换读音/译文显示、调整字号；“歌词来源”展开歌曲 ID 搜索与文件导入。

打开后先点“体验五语示例”，确认窗口、歌词与音频都能运行。

## 源码运行

开发需要 Python 3.12。`start.bat` 是源码开发入口，首次启动会创建项目内 `.venv` 并安装依赖。也可以手动运行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

构建便携版：

```powershell
.venv\Scripts\python.exe -m pip install "pyinstaller>=6.16,<7"
.venv\Scripts\python.exe scripts/build_release.py
```

`vendor/` 包含原版 eSpeak NG 1.52.0 DLL、数据与对应源码归档；源码运行也无需安装系统语音软件。使用 `scripts/build_release.py --dist-dir dist/0.3.1` 和 `scripts/zip_release.py --version 0.3.1` 构建本版。引擎来自 [eSpeak NG 官方仓库](https://github.com/espeak-ng/espeak-ng)，许可见 `vendor/espeak-ng/COPYING`，对应源码见 `vendor/espeak-ng-source-1.52.0.tar.gz`。

## 跟随网易云

1. 在网易云 Windows 客户端播放歌曲，点击“跟随网易云”。普通模式读取 Windows 媒体会话；会尝试按曲名和歌手匹配公开歌词。
2. 若状态显示“当前版本未提供可用时间轴”，请从托盘**完整退出**网易云后，点击“启动直连”，选择 `cloudmusic.exe`。程序将以绑定本机 `127.0.0.1:9222` 的调试参数启动客户端。播放歌曲后会自动识别直连通道。
3. 若自动匹配失败，可粘贴网易云歌曲 ID 或歌曲链接，再点“获取歌词”；也可导入自己的 LRC。

直连适配针对网易云 3.x 桌面版播放器，兼容旧播放按钮和新版 `btn_pc_minibar_play`。倍速使用客户端自身的 `playing/switchPlayingSpeed` 动作；仅在客户端报告歌曲倍速可用时启用，普通媒体通道则依赖 Windows 会话报告的能力。不支持时控件禁用并说明原因。客户端升级可能让直连失效；没有时间轴时只显示歌曲资料。要停止调试端口，完整退出网易云后以常规方式重启。

程序不读取登录 Cookie、不下载受保护音频、不修改网易云安装文件；联网请求仅用于公开歌曲搜索和歌词。歌词与翻译的版权归原权利人。

## 读音与时间边界

读音层是**练习提示**，不是对歌手演唱做语音识别。日语多音字、英语歌唱连读、俄语重音、法语连音/哑音和韩语音变都可能需要人工核对。法语 IPA 来自离线文本发音引擎，并非歌手实际演唱的音标；俄语普通模式只做转写而不标重音；韩语普通模式罗马字不处理跨音节音变。普通 LRC 只有逐行时间，因此不会显示伪造的逐字高亮。

汉字谐音只是第一遍辅助：忽略汉字的声调，不把谐音当歌词翻译。普通话无法完整表达法语鼻元音、英语齿间音、俄语软音、韩语收尾音；辅音簇和收尾辅音有时会多出普通话音节。请结合原唱听音，逐渐改用原音标／读音。谐音采用本地规则和音节距离，没有声学模型，也不保证为所有方言使用者找到最接近的字。

单句循环以相邻歌词行作为边界。客户端直连的进度受网易云滑块量化与回传频率限制，短于 0.8 秒的远端循环不执行；本地短于 0.1 秒的循环不执行。本地音频可否解码由 Qt 的系统解码器决定。
